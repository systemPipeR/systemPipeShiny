# AGENTS.md

Guidance for AI coding agents working in this repository.

## What this is

systemPipeShiny (SPS) is a Bioconductor R package: a Shiny GUI for systemPipeR workflows, plus RNA-seq visualization and a plot canvas.
The product contract is in `spec.md`, and the task ledger is in `Plans.md` (git-ignored).

## Sync first

```bash
git fetch upstream && git merge --ff-only upstream/devel   # Bioconductor (git.bioconductor.org)
git fetch origin                                             # GitHub mirror
```

Bioconductor pushes version bumps to `upstream/devel`. Always sync before editing `DESCRIPTION`.

## Layout

- `R/`: package source. Files are named by area: `spsCore*.R` (app core), `tab_core_*` (core tabs),
  `tab_wf_*` (workflow module), `tab_vs_*` (visualization module), `page_*` / `tab_admin_*` (login/admin),
  `spsClasses.R` (R6 `spsDb`/`spsEncryption`/`spsAccount`).
- `inst/app/`: the app project template that `spsInit()` copies. Includes `config/`, `templates/`, and `www/`.
- `tests/testthat/`: unit tests.
- `vignettes/`, `man/`: documentation. `man/` is generated by roxygen2, so never edit it by hand.
- `docs/`: pkgdown site (ignored in the build).

## Commands

```bash
Rscript -e 'devtools::document()'                     # regenerate man/ + NAMESPACE
Rscript -e 'devtools::test()'                          # tests
R CMD build . && R CMD check systemPipeShiny_*.tar.gz  # full check
Rscript -e 'BiocCheck::BiocCheck(".")'                 # Bioconductor rules
```

## Rules

- Roxygen comments are the source of truth for docs and `NAMESPACE`. Run `document()` after changing exports.
- Keep module-only packages in `Suggests`, and guard them at runtime (see `spec.md` Invariants).
- Any user-visible change gets a `NEWS.md` entry. Bump only the `z` in `x.y.z` (e.g. 1.23.0 → 1.23.1) when pushing to Bioconductor, or the builders won't propagate the change. Never change `x` or `y`; Bioconductor bumps `y` at release time.
- Follow the existing style: 4-space indents, `snake_case` internals, `camelCase` exported `sps*` functions.
- Keep AI files (`AGENTS.md`, `CLAUDE.md`, `spec.md`, `Plans.md`, `.claude/`, …) out of the build by adding them to `.Rbuildignore`.
- Don't commit or push unless asked. PRs target `devel` on GitHub (`origin`).
